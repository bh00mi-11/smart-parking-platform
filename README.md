# AI-Based Intelligent Parking Occupancy Analytics and Urban Mobility Optimization Platform

An intelligent end-to-end platform for real-time parking occupancy analytics, forecasting, vehicle detection, smart reservation, and urban mobility optimization.

## Team Structure & Module Ownership

| Folder | Module | Owner / Role | Description |
|---|---|---|---|
| `vision/` | Computer Vision & Fusion | Member 1 | Slot occupancy classification (MobileNetV3), open-zone car counting (YOLO11n), camera fusion |
| `forecasting/` | Forecasting & Analytics | Member 2 | Occupancy forecasting, arrival probability modeling, admin analytics dashboard |
| `backend/` | Backend & Services | Member 3 | FastAPI service, database, IoT/event simulator, payment integrations, Docker |
| `app/` | Driver Mobile App | Member 4 | Cross-platform mobile driver application built with React Native + Expo |
| `docs/` | Shared Documentation | Team (Shared) | System architecture, API contracts, research reports, and presentation slides |
